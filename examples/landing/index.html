Why this one

            

              

                
Session-token billing

                

                  A session token is minted per search and retired on select, so a whole
                  type-then-pick counts as one autocomplete session — the way Google bills it — with
                  nothing for you to manage.
                

              

              

                
Places API (New)

                

                  Built on the current places.googleapis.com REST API, not the legacy
                  widget — no <script> tag, no global google.maps,
                  just fetch.
                

              

              

                
Resolved place details

                

                  On select you get the full PlaceDetails — formatted address, lat/lng,
                  and typed address components — not just the prediction text.
                

              

              

                
Keyboard & ARIA

                

                  A proper combobox: arrow keys move the active option, Enter selects, Escape
                  closes, with aria-expanded / aria-activedescendant wired
                  up.
                

              

              

                
One engine, real adapters

                

                  All behaviour lives in the zero-dependency core; each adapter is a thin, idiomatic
                  binding — v-model in Vue, a hook in React, runes in Svelte, signals
                  in Solid.
                

              

              

                
Typed end to end

                

                  Config, state, suggestions and resolved details are all fully typed. Location
                  bias, field masks and region/language are all first-class options.
